# Бизнес‑аналитик с техническим образованием и 10‑летним предпринимательским опытом в оптовой торговле и производстве.

Превращаю размытые запросы бизнеса в структурированные требования и понятные модели процессов, а затем довожу до реализации: провожу обучение пользователей, презентации для стейкхолдеров и приемку результатов по согласованным критериям качества.

- **Моделирование:** BPMN 2.0.
- **Автоматизация и прототипы:** bolt.new, Telegram Bot API.
- **Документация:** User Story (USM), Acceptance Criteria, CJM, Use Case, ТЗ, ПМИ.
